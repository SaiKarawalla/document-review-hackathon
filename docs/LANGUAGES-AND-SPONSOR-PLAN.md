# Five languages and hackathon sponsor plan

Latest user instruction moves **five languages into Phase 6** and selects **iPhone Expo Go + paired-Mac local Qwen/Ollama**. Supersedes ten locales / Mac-only / standalone-only earlier proposals. Phase 7 is visual revamp and optional sponsor runtime, only on a separate instruction.

## Presentation languages

English, Spanish, Hindi, Simplified Chinese and French. Five commonly used languages chosen for the demo audience; no claim of a ranked global top five. Local checked dictionaries translate interface labels and the exact allowed canonical explanation sentences. Qwen produces a real constrained English response; translated display is explicitly labeled and does not claim fresh multilingual inference. Display language changes do not call a model, send documents to translation services, or alter an existing approved request.

Original values, names, source excerpts, filenames, original PDF pages, exact serialized request and canonical response are retained unchanged. Supported input remains the selected English synthetic templates and the measured German/English Schengen layout; Hindi/Chinese UI does not mean arbitrary Hindi/Chinese PDFs work. No fine-tuning is needed for masking; code constructs a strict allowlisted derived context.

All four extra locales have every permitted model sentence translated, nonempty dictionary checks, dynamic status/count templates and native layout captures. Native-speaker translation review remains unverified. Report current native test results in PROGRESS, not merely this planned acceptance.

## Free runtime

Use the already downloaded Apache-2.0 qwen2.5:1.5b (about 986 MB) on the Mac through Ollama with cloud disabled/loopback only. No new key, billing or model download is necessary. Encrypted minimized facts cross the trusted local Wi-Fi companion; raw documents stay in the phone. Mac must stay awake/running. Current [Expo documentation](https://docs.expo.dev/versions/v57.0.0/) was checked; SDK57 is installed. Physical iOS Expo Go requires the same free Expo account as the CLI; the already authenticated Mac account is karawalla. Never request passwords in chat.
