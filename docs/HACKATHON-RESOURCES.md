## Rules before any sponsor use

- Verify actual redemption, quota, expiry and renewal/overage terms for the available account. An advertised API key is not evidence of a funded working account.
- No money, billing activation, paid usage, automatic top-up or upgrades. If free-only use cannot be verified, leave the service unused.
- Stop using the service when free credits/access end. Local Ollama and the labeled rule-based unavailable-AI fallback remain available; a provider change requires a new exact preview/approval.
- Keep keys server-side and outside Git, screenshots/transcripts and app logs. Do not ask the user to paste secrets into chat.
- Use only the minimized allowlisted request. No raw PDF/content uploads or silent cloud fallback.
- Do not access the user's email, redeem accounts, subscribe or contact event staff without authorization for that action. Tell the user which access detail is missing and keep unrelated local work moving.
