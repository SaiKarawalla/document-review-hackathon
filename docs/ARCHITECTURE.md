# Local review boundary

Browser: synthetic fixture fetch or user File → dedicated PDF.js worker → supported template fields with page/excerpt → deterministic comparison → allowlisted reduced facts. Documents and source excerpts never enter API requests. Two slots, one edition per type, 5 MiB/10 pages/100k text/15s parser timeout. Worker termination actually stops parsing. PDF rendering is canvas-only, with bounded pixel dimensions; no PDF links/actions/scripts execute.

Node: loopback HTTP (8787) validates Host, Origin, custom header, body size and strict schema. Preview builds final Ollama /api/generate JSON, serializes once, hashes SHA-256 and stores in memory for five minutes. Send requires request ID/hash, consumes approval and sends those same bytes. No unseen retry or provider switch. One model call at a time, six attempts/minute. Fixed destination 127.0.0.1:11434, rejects redirects; checks local downloaded model tag before inference. No raw-content logs or persistent cases.

Ollama: CLI launched with cloud disabled and loopback host; Qwen2.5 1.5B downloaded instruction model on the actual laptop. 4096 token context, 768 output tokens, temperature 0, 60s default timeout, 64 KiB response envelope limit. AI selects from an enumerated sentence vocabulary for overview/explanation/follow-up; validator rejects unknown IDs, duplicates, omissions, contradiction and arbitrary factual prose. This deliberately limits generative freedom. Tests with controlled provider responses are clearly test doubles, separate from real model integration checks.

Corrections retain original raw field/page/excerpt and record confirmed/corrected state. New values recompute deterministic findings and clear summary/approval; browser requests cancel obsolete work. Reset aborts parser/model, revokes object URLs, clears fields, previews and results. Pseudonymous case alias is not an anonymity guarantee. Local process/OS/browser extensions and model logs remain outside the prototype's complete control.

Supported structure uses a notice, one exact template marker, headings, and field labels; absent required values are findings. Duplicate field labels require review. Spacing/case normalization does not erase punctuation/name/address differences. ISO dates only; invalid/ambiguous dates unresolved. Balance compares integer cents only when explicit account/currency/date match and period is valid.

Phase 4 additions: encrypted PDFs are rejected even with a blank user password by inspecting PDF permissions. Non-consistent findings show two source passages side by side; source PDF rendering is loaded on demand. Aborted/failed multi-file parses revoke partially created object URLs. Axe checks cover the reset and loaded screens; secondary text and the empty-state heading meet checked contrast thresholds.

The future FormBridge brief is recorded in FUTURE-FEATURES.md. Purpose-driven Proof Mode is not implemented. Any later purpose policy must preserve the current structured boundary and invalidate approval when purpose changes. Budget rule: local-only inference, no paid usage or sponsor activation.
